# 💰 Expense Tracker

A lightweight, responsive web-based expense tracking application built with pure HTML, CSS, and JavaScript. Easily log daily expenses, categorize transactions, and keep track of your overall spending directly from your web browser.

---

## ✨ Features

- **Add & Track Expenses:** Quickly record income and expenses with clean transaction details.
- **Dynamic Balance Calculation:** Automatically updates your total balance, income, and expense totals in real time.
- **Categorization:** Classify expenditures to understand where your money goes.
- **Persistent Data:** Saves transaction history locally in the browser (`localStorage`), so your data stays saved even after refreshing.
- **Responsive Design:** Optimized for both mobile devices and desktop screens.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and form elements.
- **CSS3:** Custom styles and responsive layout.
- **JavaScript (ES6+):** Dynamic DOM manipulation and state management using `localStorage`.
